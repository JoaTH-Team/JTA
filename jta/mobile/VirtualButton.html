class VirtualButton

package jta.mobile

extends FlxSprite

@:directlyUsed

A virtual touchscreen button.

The button's action is the logical input action it represents, while imageName controls which button graphic is displayed.

This allows the same A graphic to represent both jump in gameplay and confirm in menus.

Input state is tracked per button (not per touch), so sliding a finger onto a button counts as a press and sliding off counts as a release. The state is refreshed once per frame by MobileInput's plugin, right after Flixel updates its touch input and before the state updates.
