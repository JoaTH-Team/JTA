class TextUtil

package jta.util

@:directlyUsed@:nullSafety(Loose)@:nullSafety

Helpers for making text in the game's style (the current language's font, white with a black outline).

Static variables

@:value("main")staticfinalread onlyDEFAULT_FONT:String = "main"

Font used when the current language doesn't set one (or its font can't be found).

Static methods

staticgetFont():String

Gets the font for the current language: $FONT_NAME in the language's data.csv (a file in assets/fonts/), falling back to DEFAULT_FONT.

Returns:

The font name, ready for setFormat().

@:value({ size : 24, text : "", fieldWidth : 0 })staticmake(x:Float, y:Float, fieldWidth:Float = 0, text:String = "", size:Int = 24, ?align:FlxTextAlign, ?color:FlxColor):FlxText

Makes a text in the game's style: current language's font, black outline. Same order as new FlxText(), plus alignment and color.

var title = TextUtil.make(0, 20, FlxG.width, 'Hello', 40, CENTER, FlxColor.YELLOW);
