class SoundGroup

package jta.audio

extends FlxSoundGroup

A group that holds a list of sounds. Unlike FlxSoundGroup, this allows to change the time, and pitch of sounds. Each sound in group will be synced with each other.

Constructor

new(?volume:Float)

Variables

pitch:Float

The current pitch of the group. When changed, all sounds are pitched to this value.

read onlyplaying:Bool

Whether the group is currently playing, or not.

time:Float

The current time of the group. When changed, all sounds are timed to this position.
