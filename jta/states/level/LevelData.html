typedef LevelData

package jta.states.level

The contents of assets/levels/<world>/<level>/level.json. Every field except name is optional.

The level's ID is its folder path, e.g. world1/lev1. Next to level.json, the loader looks for map.csv, objects.csv and (optionally) background.csv.

Fields

@:optionaloptionalzoom:Null<Float>

Camera zoom. Defaults to 1.

@:optionaloptionaltimeLimit:Null<Float>

Time limit in seconds. If set, a timer counts down on the HUD and the player loses a life when it hits 0. Leave it out for an untimed level.

@:optionaloptionaltileset:Null<String>

Tileset folder in images/tiles/. Uses main.png for the map and background.png for the background layer.

@:optionaloptionaltileSize:Null<Int>

Tile size in pixels (tiles are square). Defaults to 16. Also used as the object grid size.

@:optionaloptionaltileProperties:Null<Array<TileProperty>>

Special tiles in map.csv: one-way platforms, non-solid tiles, bouncy or deadly tiles, etc. See TileProperty.

@:optionaloptionalspawn:Null<LevelPoint>

Where the player spawns, in pixels.

@:optionaloptionalplayer:Null<String>

Player ID to spawn. Defaults to mainplayer.

@:optionaloptionalorder:Null<Int>

Sort order within the world (lower comes first). Defaults to 0, ties are sorted by ID.

name:String

Display name. If it starts with $, it's treated as a locale key and looked up in levels.csv.

@:optionaloptionalmusic:Null<String>

Music track in music/ to play when the level starts.

@:optionaloptionalhidden:Null<Bool>

If true, the level is loaded but doesn't show up on the level select (e.g. test levels).

@:optionaloptionalendCutscene:Null<String>

Video (in videos/, no extension) played after the level is completed, e.g. cutscenes/world1.

@:optionaloptionalcover:Null<String>

Image in images/menu/level/ used on the level select. Falls back to the placeholder.

@:optionaloptionalcameraFollow:Null<Bool>

Whether the camera follows the player. Defaults to true.

@:optionaloptionalbgColor:Null<String>

Background color, e.g. "#00B5E2".

@:optionaloptionalbackgroundScroll:Null<LevelPoint>

Scroll factor of the background tile layer. Defaults to {"x": 1, "y": 1}.
