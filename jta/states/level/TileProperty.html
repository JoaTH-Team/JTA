typedef TileProperty

package jta.states.level

import jta.states.level.LevelData

Special behavior for one or more tiles of a level's main tilemap (map.csv). Used in level.json (tileProperties) and by Level.loadMap() / Level.setTileProperty().

"tileProperties": [
    { "tile": 9, "range": 3, "collision": "oneway" },
    { "tile": 12, "effect": "bounce", "power": 450 },
    { "tile": 13, "collision": "none", "effect": "kill" }
]

Fields

tile:Int

The tile's number in map.csv (its position in the tileset, counting from 0).

@:optionaloptionalrange:Null<Int>

How many tiles in a row (starting at tile) get these properties. Defaults to 1.

@:optionaloptionalpower:Null<Float>

Strength for the effect (e.g. how high bounce launches you).

@:optionaloptionaleffect:Null<String>

What happens when the player touches the tile (or stands in it, for non-solid tiles): - kill: kills the player - bounce: launches the player up (power = speed, default 400) - bounceLeft / bounceRight: launches the player sideways (power = speed, default 300) - or the name of a custom effect added by a level script with registerTileEffect()

@:optionaloptionalcollision:Null<String>

Which sides of the tile are solid. Defaults to solid. - solid / any: solid on every side (the normal behavior) - none: not solid at all (you pass through it) - oneway / platform: can be stood on, but you can jump up through it from below - up, down, left, right, wall (left + right): only those sides are solid. Combine them with |, e.g. "up|left".
